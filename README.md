An intelligent, real-time multi-language translation web application built with **Python**, **Streamlit**, and **Deep-Translator** (Google Translate Engine), complete with **Text-to-Speech (gTTS)** pronunciation and file export features.

---

## 📌 Features

- **Multi-Language Support**: Translates between 20+ world languages including English, Spanish, French, German, Hindi, Gujarati, Chinese, Japanese, Russian, Arabic, and more.
- **Auto-Detection**: Automatically identifies source language from input text.
- **Language Swapping**: Instantly flip source and target languages with a single click.
- **🔊 Text-to-Speech (TTS)**: Listen to native audio pronunciation of translated content.
- **Instant Copy**: Built-in formatted code block for one-click clipboard copying.
- **File Export**: Download original and translated text as a clean `.txt` file.
- **Real-Time Word & Character Counter**: Monitors input text statistics dynamically.

---

## 🛠️ Tech Stack

- **Frontend & App Framework**: [Streamlit](https://streamlit.io/)
- **Translation API Engine**: [Deep-Translator](https://github.com/nidhaloff/deep-translator)
- **Audio / Speech Synthesis**: [gTTS (Google Text-to-Speech)](https://gtts.readthedocs.io/)
- **Language**: Python 3.9+

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/a-b-infotech/CodeAlpha_LanguageTranslationTool.git
cd CodeAlpha_LanguageTranslationTool
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Application
```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`.
